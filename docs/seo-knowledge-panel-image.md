# Knowledge Panel Image Follow-Up

Use this after the refreshed SEO assets are deployed.

## Preferred Image URLs

- Wide social/search preview: `https://intothebattle.com/og-intothebattle.png`
- Square brand/entity image: `https://intothebattle.com/brand-identity-square.png`

## Why These Exist

Google can use Organization structured data, page metadata, image sitemaps, and crawlable image URLs to better understand the brand image. The site now exposes:

- Organization `logo` as a square PNG.
- `primaryImageOfPage` on indexed public pages.
- Open Graph image dimensions and alt text.
- An image sitemap entry for the wide preview and square brand image.
- HTTP smoke coverage for both image URLs and the shared public CSS.

Reference:

- Google Organization structured data: https://developers.google.com/search/docs/appearance/structured-data/organization
- Google Image SEO best practices: https://developers.google.com/search/docs/appearance/google-images
- Google image sitemap documentation: https://developers.google.com/search/docs/crawling-indexing/sitemaps/image-sitemaps
- Google knowledge panel image feedback: https://support.google.com/knowledgepanel/answer/7534842

## Manual Google Step

If the knowledge panel already has the wrong featured image, claim or use the verified account for the panel, choose **Suggest edits**, edit the image, and submit the direct image URL:

`https://intothebattle.com/brand-identity-square.png`
