## Shared Production Rules

- Original characters and creatures only; no franchise imitation.
- Six heroes must have distinct silhouettes at overlay scale.
- Materials must translate cleanly to optimized PBR GLBs.
- Avoid emoji medallions, neon dashboard rings, black banner slabs, and whole-model pulsing.
- Preserve clear faces, practical proportions, restrained bloom, and foreground effect readability.
- Production uses the approved hybrid: Direction 02 on the left and Direction 01 on the right.
